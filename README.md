## 🚀 स्थानीय विकास व सेटअप (Local Setup & Development)

### 1. रिपॉजिटरी क्लोन करें (Clone Repository)
```bash
git clone https://github.com/accaiwork/rainaksh-network.git
cd rainaksh-network
```

### 2. निर्भरताएँ इंस्टॉल करें (Install Dependencies)
```bash
npm install
```

### 3. डेवलपमेंट सर्वर प्रारंभ करें (Run Dev Server)
```bash
npm run dev
```
लोकल ब्राउज़र में खोलें: `http://localhost:3000`

### 4. प्रोडक्शन बिल्ड तैयार करें (Build for Production)
```bash
npm run build
```
बिल्ड आउटपुट `dist/` फ़ोल्डर में उत्पन्न हो जाएगा जिसे किसी भी होस्टिंग प्लेटफॉर्म (Vercel, Netlify, Cloud Run, GitHub Pages) पर डिप्लॉय किया जा सकता है।
